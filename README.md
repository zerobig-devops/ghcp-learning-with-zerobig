# GHCP Learning with Zerobig

이 저장소는 Azure 시스템 관리자(SA)와 시민개발자(코드에 익숙하지 않은 사용자)를 대상으로 GitHub Copilot(이하 Copilot)을 활용해 빠르게 생산성을 높이는 방법을 학습하도록 설계된 샘플 프로젝트입니다.

목표
- Copilot의 기본 사용법과 실무 적용 예시 소개
- Low-code/No-code 환경에서 Copilot을 활용하는 방법 제시
- Azure 서비스(Function, Logic Apps, Power Platform)와의 연동 예제 제공
- 단계별 실습(초급 → 중급)과 해설 제공
